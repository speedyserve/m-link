# Demo scenarios

- **CUS001 — Lê Polo:** Priority customer, recent 500M VND inflow, idle CASA and a deposit
  maturing in five days. The Agent allows selling and recommends cash optimization then renewal.
- **CUS002 — Hoàng Lan:** Priority customer with repeated negative interactions and an open
  complaint. The Agent returns CUSTOMER CARE FIRST / DO NOT SELL and no product recommendation.
- **CUS003 — Nguyễn Minh:** Normal activity and no material event. The Agent returns NO ACTION
  and advises against unnecessary outreach.

All fixtures are deterministic relative to `DEMO_REFERENCE_DATE`; the mock result never depends
on inferred balances or random values.
